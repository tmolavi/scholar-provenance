# ScholarProvenance Project Roadmap

## Phase 1: Foundation (v0.1.0) — *Current Release*
- [x] Portable, vendor-neutral canonical `SKILL.md` specification.
- [x] Machine-readable evidence ledger with strict 16-type taxonomy.
- [x] Zero-fabrication citation verification against OpenAlex, Crossref, and arXiv.
- [x] Automated 12-gate quality verification engine.
- [x] Multi-format publication generator: HTML, PDF, DOCX, LaTeX, BibTeX.
- [x] First-class RTL typography and font fallbacks for Persian and Arabic.
- [x] Pure-SVG charting and systems architecture vector diagrams.
- [x] Five localized primary documentation editions (EN, FA, TR, AZ, AR).
- [x] Adapters for Claude Code, Antigravity, Hermes, Codex, and Generic MCP.

## Phase 2: Enhanced Connectors & Scientific Integrations (v0.2.0)
- [ ] Direct Zenodo DOI registration client for automated preprint deposition.
- [ ] Specialized biomedical search connector for PubMed Central and Europe PMC.
- [ ] Computer Science DBLP connector for conference ranking and BibTeX harvesting.
- [ ] Interactive terminal TUI for live evidence ledger inspection.

## Phase 3: Collaborative & Multi-Agent Swarms (v0.3.0)
- [ ] Decentralized evidence ledger verification over peer review nodes.
- [ ] Native Typst typesetting backend alongside WeasyPrint.
- [ ] Expanded multilingual registers for Chinese (Simplified), Spanish, French, and German.
