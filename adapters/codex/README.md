# OpenAI Codex & ChatGPT Workspace Adapter

Use **ScholarProvenance** within OpenAI Codex or ChatGPT Custom GPT / Workspace configurations.

## Setup Instructions

1. Paste `instructions.md` into your Custom GPT or Project Custom Instructions.
2. If code execution / Advanced Data Analysis is enabled, upload `scholar_provenance/` package files or install from GitHub:
   ```bash
   pip install git+https://github.com/tmolavi/scholar-provenance.git
   ```
3. Attach `research-project.yml` as the starting configuration manifest.
